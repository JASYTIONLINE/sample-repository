# Full-Stack Foundations — Guided Build Repository

## Purpose

This repository is a **single, continuous learning project** used to build full-stack fundamentals step by step.  
It is not a collection of disconnected demos. Each lesson builds on the last, using the same files, the same structure, and the same habits.

By the end of the series, this repository represents:
- A real project history
- Clean version control practices
- A portfolio-ready foundation in HTML, CSS, and beyond

## How This Repository Works

### One Repository, One Narrative

- All lessons live in **this single GitHub repository**
- We do **not** create a new repo per lesson
- Changes are incremental and intentional
- Files are added only when they serve the lesson
- Temporary or learning-only files are removed when no longer needed

This mirrors how real projects evolve over time.

### Version Control as a Background Habit

Git is used throughout the project, but it is **not always the focus**.

You will regularly:
- Check context with `git status`
- Save files and verify results
- Commit changes with clear intent
- Use branches when appropriate

Version control supports the learning—it is not the lesson itself after Lesson 1.

### Clean End States Matter

Every exercise ends in a **clean, understandable state**:
- No leftover experiments
- No confusing file names
- No broken or unused code
- The repository should always make sense if someone opens it fresh

Think of each lesson as something you would be comfortable showing to:
- A classmate
- An instructor
- A future employer

## Current Structure

At the start of Lesson 2, the repository includes:

- `index.html` — the main entry point for the project
- `README.md` — this file, explaining the project and how to navigate it

As lessons progress, the structure will expand **deliberately**, not all at once.

## Learning Philosophy

This project is designed so that:
- A beginner can succeed without guessing
- Every step explains **what is happening** and **why it matters**
- Instructions assume the instructor is not present later
- You are learning how to read output, not just type commands
- Good habits are reinforced through repetition, not lectures

## Where This Is Going

- Lesson 1 established trusted workflow and version control habits
- Lesson 2 builds HTML and CSS on top of that foundation
- Future lessons will extend this same project into more advanced front-end and full-stack concepts

This repository is your **through-line** from beginner to capable builder.
